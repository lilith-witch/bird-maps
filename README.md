## bird-maps
Seminary project created for subject Programming in Python 1 at FNSPE CTU Prague.
An Jupyter Notebook, which generates various visualizations of data from avif.birdlife.cz database. 

Here I provide anonymised sample data downoloaded from the source. To use data of your own selection (species, timeframe), you have send a manual request to the database.
They only require you state a reason (any reason like own reseach, hobby interest will suffice) and provide your e-mail address. 
These raw data countain names of authors of observation, be mindful of that. 

This project does not use this part of data in any way (it discards them).
